# PythonGame
Python Compiler Game

The game is an educational project designed to teach the fundamentals of Python through interactive gameplay. Players control a robot using code and complete tasks by employing variables, conditionals, loops, functions, and other basic Python constructs.

The learning process is structured around a system of practical quests: players learn a new language construct and immediately apply it to solve a challenge within the game world. Coding errors help players understand the underlying issues and debug their programs.

The project aims to make learning Python fundamentals more practical and interactive by combining programming with gameplay.
